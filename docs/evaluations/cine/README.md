# Cine run reports and evaluations

Dated acceptance runs, A/B evaluations and fix reports for the Cine agent
(`examples/cine`). They record what was true when each was written; paths,
tool names and gate codes inside them may since have changed. The current
behaviour is defined by `examples/cine/config.yaml`, the skills under
`examples/cine/skills/` and `film-analysis/references/production-handoff.md`.

- `CINE_*.md` — individual reports, named by topic.
- `cine-live-20260907/` — artifacts of the 2026-09-07 live acceptance run.
- `cine-workflow-20260907/` — protocol, inputs and judge outputs of the
  2026-09-07 workflow A/B evaluation.
