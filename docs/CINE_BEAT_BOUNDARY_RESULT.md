# Cine 剧本与表演时间边界优化

后续发布状态：共享 Cine 已发布至 v25，见 [发布与真实 Topic 验证](CINE_SKILL_RELEASE_20260910.md)。下文保留优化阶段的测试记录。

## 本次修改

- `novel-script`：用目标、选择、信息和关系变化划分戏剧节拍；不默认给微动作写起止时间。短场景输入充分时直接写戏，不强制补大纲。
- `novel-storyboard`：明确节拍、镜头、生成段不一一对应。镜内按因果与先后展开，只保留真实切点、总时长和必要同步锚点；用户指定的踩点、口型不删除。
- Cine 配置：派发时请求自然剧本和独立分镜计划，不请求每个动作的 start/end；两份核心规则同步预载。
- 评测模板：加入自然短场景和明确同步例外。测试请求不向模型泄露评审标准，不做场景级返修。

没有新增 schema、运行状态机或依赖。原生 seed 只带预算秒数，export 原样传递提示词，V3 导入端保留镜头时长；未发现这些代码自动合成逐动作时间轴，因此没有改写其运行逻辑。新增回归检查防止未来出现此类转换。

## 生效范围与人工验收

源码和独立验收会话已更新；共享 Cine 模板尚未发布，本轮未重启 6767。发布需先确认服务空闲和用户的重启选择。

发布后给 Cine 一个新题材，只要求剧本和逐镜计划时长：检查剧本是否讲完整行动及其反应，而非每个眼神/伸手的秒表。再明确要求一个音乐同步时点，检查它是否被保留。创作自然度、电影感及最终声画执行仍需另做成片验收，不用文本或结构测试代替。
